## SVG Generation

  <p>
    Use <code>generateZenthcloudLogoSvg()</code> to get copy-paste ready SVG markup for non-React contexts.
  </p>

```tsx
import { generateZenthcloudLogoSvg } from "@zenthcloud/kumo";

// Generate glyph SVG (cloud only)
const glyphSvg = generateZenthcloudLogoSvg({ variant: "glyph" });

// Generate full logo SVG
const fullSvg = generateZenthcloudLogoSvg({ variant: "full" });

// Generate black logo
const blackSvg = generateZenthcloudLogoSvg({ color: "black" });

// Copy to clipboard
await navigator.clipboard.writeText(
  generateZenthcloudLogoSvg({ variant: "glyph", color: "color" }),
);
```
