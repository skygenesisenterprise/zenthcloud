Initial release of `@zenthcloud/bot`, the official zenthcloud Community bot. Ships a TypeScript package with a client, a slash command registry (`/about`, `/help`, `/docs`, `/links`, `/status`, `/version`), a dedicated slash command registration script, environment-based configuration, an isolated read-only GitHub integration, optional zenthcloud API access through `@zenthcloud/sdk`, configurable GitHub notification routing, community onboarding roles and a Docker deployment setup.
